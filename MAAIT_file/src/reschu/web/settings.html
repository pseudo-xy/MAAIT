Boats Panel

#TypeBehaviourTier StartExitKnown?
Type is the true class. Behaviour is only selectable for enemies (aggressive / standoff) — civilian and friendly boats have a fixed behaviour that matches their type. Tier only applies to standoff enemies (low = 4 knt, med = 9 knt). Known? = starts already identified. Each behaviour steers itself — aggressive boats chase the nearest USV or friendly they detect, civilians random-walk, friendlies transit across and exit, standoff enemies head to a random edge — so there is no fixed end goal to set.

Comms Schedule — per USV: when each comms state starts and how long it lasts

For each USV, set when each comms state begins (start, minutes into the mission) and how long it lasts (duration). Leave start blank for a state you don't use. This drives the comms signal shown in Health & Status.

USV Control — start position · control mode · timeline

USVstart (x,y)modesfuel start %timeline (drag handles · click a segment to change mode)total
The timeline spans the whole mission. Drag the handles to set which mode controls each stretch — e.g. dragging so Manual covers 7→12 means that USV is manually controlled from minute 7 to 12. Click a segment to change its mode. The three segments always fill the mission. Fuel start % is the fuel each USV begins the mission with (it burns about 6% per minute). Below 20% a USV can no longer be sent back to base.
